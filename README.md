# GlobeTrotter — Smart Travel Planning & Itinerary Platform

GlobeTrotter is a full-stack travel planning platform designed to allow users to explore destinations, build dynamic itineraries, manage trip budgets with visual charts, and share their experiences with a global community.

## 🛠️ Tech Stack Snapshot

- **Frontend:** React (Vite, TypeScript), Tailwind CSS, React Query, Recharts.
- **Backend:** Node.js, Express, TypeScript, Zod validation.
- **Database:** Supabase (PostgreSQL, Auth, Storage).
- **Deployment:** GitHub Pages (Frontend), Railway (Backend).
